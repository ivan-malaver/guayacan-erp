# Manuales

Los manuales en Word, PDF y Excel no se guardan en el repositorio (son binarios grandes y cambian poco): vienen en la
carpeta `entregables/` del paquete, que está en `.gitignore`. Súbalos a Drive o a un *release* de GitHub.

| Manual | Archivo en `entregables/` |
| --- | --- |
| Documento técnico para desarrolladores | `GuayacanERP_Documento_Tecnico_Desarrolladores_v5.2.docx` / `.pdf` |
| Arquitectura y diccionario (con anexo A) | `GuayacanERP_Arquitectura_y_Diccionario_v5.2.docx` / `.pdf` |
| Versión 5 aplicada a la operación de la finca | `GuayacanERP_Version_5_aplicada_operacion_integral_de_la_finca_v5.2.docx` / `.pdf` |
| Diccionario de datos | `GuayacanERP_Diccionario_de_Datos_v5.2.xlsx` |
| Mapa de APIs y modelos | `GuayacanERP_Mapa_de_APIs_y_Modelos_v5.2.xlsx` |
| Trazabilidad (casos de uso, requerimientos, tablas, pruebas) | `GuayacanERP_Trazabilidad_v5.2.xlsx` |
| Proyección financiera de la adopción | `GuayacanERP_ApendiceA_Adopcion_Proyeccion.xlsx` |

`generadores/gen_proyeccion.py` regenera la proyección de la adopción (todas las cifras con fórmulas de Excel).
